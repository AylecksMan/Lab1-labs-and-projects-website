Rhythm Games

These are the common rhythm game cabinets you'll find!

All of these machines, and more use an Eamusement card.

Sound Voltex

Sound Voltex is a long-running Konami rhythm game. It has the user control four main buttons, two lower "fx" buttons, and two knobs at the top. This game is known for its high skill ceiling and it's simplicity to pick up.

Wacca

Wacca is a newer rhythm game by Marvelous. It has the user pressing and sliding their fingers in a large circle around the screen. This game is known for its track list, with direct collaboration with popular EDM group: Hardcore Tano C.

JuBeat

JuBeat is an older, classic Konami rhythm game. This game has a 4x4 button layout over a screen and the user must press the buttons at the indicated time. This game is known for its simplicity to play without any prior knowledge of rhythm games.

Dance Dance Revolution

Dance Dance Revolution is a classic Konami rhythm game. This has the player pressing 5 different buttons with their feet to the music. This game is known for its cardio workout, and long running legacy.

Mai Mai

Mai Mai is an older SEGA rhythm game that recently picked up a strong following. This game has buttons along the radius of the screen and a touchscreen. This game is known for its fantastic tracklist and high skill ceiling.

Taiko no Tatsujin

Taiko no Tatsujin is a Bandai Namco Rhythm game. This game features a drum which is struck on the rims or the center. This game is known for its beginner-friendly experience and unique gameplay.

BeatMania IIDX

BeatMania IIDX is a classic Konami rhythm game. This features 7 keys and a turntable.
